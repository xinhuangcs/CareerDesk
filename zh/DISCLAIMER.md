## 本地数据与凭据

CareerDesk 桌面版没有由项目维护者运营的用户账号、中心数据库、同步服务、遥测服务或云端 CareerDesk 后端。桌面进程只绑定本机回环地址，业务数据库、简历、上传文件、配置和日志保存在使用者自己的设备上。项目维护者不能通过 CareerDesk 访问这些本地数据。

安装式桌面版把受支持的 API Key 保存到当前操作系统的原生凭据存储；源码运行方式使用使用者本机的私有 `.env`。设置接口不会把 Key 原文返回给前端。`.app` / `.exe` 不包含使用者的运行数据或系统凭据，转发安装包不会把这些内容一起发出，卸载应用也不会自动删除它们。

自定义数据目录迁移会先生成校验备份、恢复并验证新副本，最后才切换配置；旧目录和已经恢复出的副本不会自动删除。活动 SQLite 数据不应放入常见同步盘或网络盘。`.jpbak` 包含业务数据和历史对话原文，不包含配置、系统凭据、日志或可重建的全文/向量索引；它有完整性校验但不加密、不签名。使用者自行负责设备安全、凭据保护、独立备份和适当的存储加密。

## 联网与第三方数据流

CareerDesk 只有在相应功能和配置允许时才会发起下列外部连接：

| 场景 | 触发方式与可能发送的内容 | 接收方 |
|---|---|---|
| 云端 LLM | 使用者配置云模型并发起 AI 操作；会发送完成当次操作所需的提示、对话及相关简历、岗位、调研、偏好、题面、rubric、证据或回答材料。简历适配和面试出题可能发送完整可提取简历文本与完整已确认 JD。 | 使用者选择的模型厂商或兼容接口运营方 |
| 对话 Embedding | 使用者单独开启语义增强并配置 OpenAI Key；发送待向量化的聊天片段及检索查询。不开启时仍可使用本地全文检索。 | OpenAI `text-embedding-3-small` |
| 公司调研搜索 | 使用者单独开启联网调研；发送公司名称、岗位名称和检索查询，不在搜索查询中发送简历或对话内容。 | 已配置的 Tavily、Brave、Google Programmable Search、自托管 SearXNG，或可关闭的 DuckDuckGo 非官方兜底 |
| 调研网页读取 | 调研随搜索结果发起只读 GET；公开页面正文用于当次操作，不保存网页快照。 | 搜索命中的网站 |
| 源码安装或构建 | 可能发送包名、版本和包管理器通常使用的网络元数据。 | Python/npm 包仓库或配置的镜像 |
| 外部链接 | 使用者主动点击。 | 目标网站 |

仅保存 API Key 不会自动授权独立的 Embedding 或联网调研。深度调研与 DuckDuckGo 非官方兜底各有独立开关。已经发出的请求无法撤回。第三方如何保留、训练、处理或披露数据，以及其价格、配额、安全和可用性，由使用者与该服务之间的条款和设置决定。维护者不代收 API 费用、不控制第三方服务，也不对其行为或输出负责。

简历在模型操作前不会自动删除姓名、邮箱、电话、学校、公司或经历，因为这些内容可能是请求分析所需的材料。超长材料压缩可能产生多次模型调用；宿主对模型输出的清洗不表示原始输入已匿名化。应用会在敏感操作附近展示相关材料范围，使用者应在继续前核对。

日志、错误和指标不记录简历、JD、调研报告或适配报告正文，只可能记录任务类型、版本、状态、输入长度或 token、延迟、失败类型及非敏感摘要。真实用户简历不会自动进入评测、训练或回归数据。

`APP_STRICT_OFFLINE=true` 会在应用进程内暂停云模型、远程 Embedding、搜索和网页读取，只允许本机回环地址的本地模型服务。源码依赖安装发生在应用启动之前，不受该开关控制；如需从第一条命令开始离线，应提前准备依赖或使用自包含构建。

仓库保留可选的 Docker/server 运行形态，但维护者不运营公共实例。任何人自行部署多人或公网实例时，应独立负责身份认证、TLS、主机安全、访问控制、日志、备份、凭据、用户告知和适用隐私规则。访问或参与 GitHub 仓库时，GitHub 也会按其自身政策处理相关数据。
